Baton is one DevTools panel for devs and QAs: inspect, mock and replay requests; flip storage flags and cookies; decode JWTs; capture screenshots, recordings and a full timeline; and file bugs straight into Azure Boards.

Nine tabs, one panel

Everything a bug report needs, in the place you are already working.

Network

Requests you can search and hand off

Live requests with search across request and response bodies, method/status/domain filters and slow calls flagged in orange and red. Multi-select to copy cURL, copy for AI or export to Bruno. Per request: replay it editable from the page, mock it, or decode the JWT in its auth header.

Mocks

Change the response without a backend

Mock responses (status, body, delay, GraphQL operation), delay, redirect, swap host, modify headers, block, inject CSS and inject JS. Toggle and reorder rules, pause all, watch hit counts, and export the set for your team.

Storage

Flags, cookies and a change history

Booleans become switches, cyclers rotate a key through values on a keyboard shortcut, and cookies are editable down to every attribute (HttpOnly included). History shows every change with the code that made it, and a one-click rollback. Lock a key so the page can't touch it.

Console

Errors with stacks, and a scratchpad

Errors and warnings with full stacks, plus a place to run code in the page (await works) and save the snippets you keep reaching for.

Timeline

One ordered story of the session

Clicks, typing (passwords masked), selects, navigation, requests, errors, storage changes and mock hits in a single list. Instant replay of the last 30 seconds, minute or five minutes — and it writes your repro steps for you.

Replay

Deterministic record & replay

Record captures the starting storage and cookies, every fetch and XHR response, the clock, Math.random, crypto randomness and your input. Replay restores all of it so the bug happens again — even if the backend has moved on.

Bug report

From symptom to filed ticket

Title, severity, steps, expected and actual, annotated screenshots, recordings that play in sync with the timeline, GIFs, failed requests, console errors and storage. Copy as Markdown, download it, or create the bug in Azure Boards.

Tools

JWT, Base64, URL and .npmrc

Decode a JWT and read its claims and expiry, edit and re-sign it, or verify it with a secret. Encode and decode Base64 and URLs. Open your .npmrc, see the credentials in it, and rotate an Azure DevOps PAT everywhere in the file.

Links & Settings

Team bookmarks and connections

Shared team links, also in the toolbar popup. Connect Azure Boards with a PAT pasted in or read from your .npmrc, and add a GIPHY key for GIF capture.

The part that saves the afternoon

Deterministic replay. A recorded session pins down everything the page saw — the API responses, the clock, every source of randomness and each thing you clicked or typed. Press replay and the same bug happens again, on your machine, without the staging environment agreeing to cooperate.

Minimize. Point Baton at an error and it runs delta debugging to find the fewest steps that still cause it, so the repro in your ticket is three lines instead of thirty.

Hand it over. Export the session as a .baton-session.json file and attach it. A developer imports it and replays the QA's bug exactly as it happened.

Install

Load Baton unpacked from the repository — it takes about a minute.

  1. Download the extension. Grab the repository as a ZIP and unzip it, or clone it with git clone https://github.com/sjayjay005/baton.git.
  2. Load it into Chrome. Open chrome://extensions, turn on Developer mode, click Load unpacked and pick the baton folder.
  3. Open the panel. Open DevTools (F12 or ⌘⌥I) and pick the Baton tab — check the » menu if it is hidden. Reload the page once so Baton hooks in from the start.
  4. Optional, for Inject JS rules. Open Baton's Details in chrome://extensions and turn on Allow user scripts (Chrome 138+; older versions use Developer mode).

Requires Chrome 120 or later.

Your data stays in your browser

No account, no analytics, no Baton server.

Baton talks to exactly two outside services, and only when you ask it to: dev.azure.com when you connect Azure Boards or create a bug, and api.giphy.com when you search for a GIF. Settings, rules, links, snapshots, screenshots and recordings are stored locally by the extension and never sent anywhere else. Read the full privacy policy.
