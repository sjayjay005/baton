Support

Baton – Dev & QA Toolkit · v0.5.1

Baton is maintained on GitHub, and that is the fastest way to get help.

Report a bug or ask a question: open an issue on the repository. Including your Chrome version, the Baton version and what you expected to happen gets you an answer much faster — and if the bug is in a page you can share, a Baton session export is the perfect attachment.

  • Issues and feature requests: github.com/sjayjay005/baton/issues
  • Source, releases and the README: github.com/sjayjay005/baton
  • Privacy questions: see the privacy policy, then open an issue if anything is unclear.

Common problems

The Baton tab isn't in DevTools

DevTools panels hide behind the » overflow menu when the window is narrow — look there first. If it is genuinely missing, close and reopen DevTools after loading the extension.

The panel is empty, or requests aren't showing up

Baton hooks into the page at load time, so reload the page once with DevTools open. Response bodies only exist for requests that were made while DevTools was open — a request from before you opened it can be listed without a body.

A mock isn't taking effect

Check that the rule is toggled on and that Pause all is off. Rules are ordered, and the topmost matching rule wins. Mocked fetch and XMLHttpRequest calls never reach the network, so they do not appear in the Network tab — look at Recent mock hits in Mocks, or the Timeline, to confirm a hit. Synchronous XHR is not mocked. Redirect, host-swap, header and block rules use Chrome's declarativeNetRequest, where regular expressions must be RE2-compatible.

Inject JS rules do nothing

They need user scripts to be allowed: open Baton's Details in chrome://extensions and turn on Allow user scripts (Chrome 138 and later; older versions rely on Developer mode).

Replay doesn't reproduce the bug

A session covers a single page load — a full navigation ends the recording, though SPA route changes are fine. Not captured: WebSockets, Web Workers, server-side state, synchronous XHR, and password or secret fields. If your app validates a token locally, export with Mask secrets off (and then share only inside your team).

Azure Boards won't connect, or a bug won't file

Check that the personal access token is still valid and has work-item write scope for the right organisation; re-paste it, or read it from your .npmrc, in Settings. Attachments over 60 MB are rejected by the upload.

Screenshots only show part of the page

That is expected: capture is limited to the visible viewport.

Requirements

Chrome 120 or later. Baton is a DevTools extension, so it does its work while DevTools is open on the tab you are debugging.

Not supported yet

Jira, GitHub, Linear and Slack integrations, AI summaries and hosted share links are planned rather than available. Requests and votes for them are welcome in the issue tracker.
